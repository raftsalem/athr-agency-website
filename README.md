# Athr Agency Website

موقع عربي RTL ثابت لوكالة Athr Agency، باستخدام HTML وCSS وJavaScript فقط.

## قبل النشر
1. افتح `script.js`.
2. استبدل `20XXXXXXXXXX` برقم واتساب الوكالة بصيغة دولية بدون + أو مسافات، مثال تنسيقي فقط: `2010XXXXXXXX`.
3. استبدل نماذج الأعمال التصورية بمشاريع حقيقية وصورك المعتمدة.
4. راجع نصوص الخدمات وبيانات التواصل.

## النشر على Cloudflare Pages
- Framework preset: None
- Build command: `exit 0` (أو اتركه فارغًا إذا كانت الواجهة تسمح)
- Build output directory: `/` (جذر المستودع)
- Production branch: `main`

الملفات الرئيسية: `index.html`, `style.css`, `script.js`.
